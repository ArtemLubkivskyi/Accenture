## 🍷 Day 1: Data foundations

Exploring the **Red Wine Quality** dataset (1,599 wines, 11 chemical features, quality score 3–8).

**What's inside:**
- Data exploration: counts, means and medians per quality level
- Min-Max scaling, done by hand and checked against scikit-learn
- Correlation matrix and heatmap
- Outlier detection with the IQR rule
- Boxplots and scatter plots with written observations
- K-fold cross-validation split (k = 3)
- Feature engineering: SO₂ ratio, total acidity, alcohol level groups, date features

**Key finding:** alcohol is the feature most associated with quality (r = 0.48). Average quality rises from 5.30 for low-alcohol wines to 6.44 for high-alcohol ones.
